Methodology note

An earlier run was excluded; filesystem isolation was limited

The first historical fixture exposed the seeded regression commit in Git history. Prime correctly diagnosed it but then used git revert, so that $0.3561798 sample was excluded as contaminated. The scored run used a standalone one-commit target repository, and its event trace shows no access to external history. It was not an OS-hermetic sandbox, however: Prime inherited the host user’s filesystem permissions. One retained pre-inference real-task parser failure cost $0.
