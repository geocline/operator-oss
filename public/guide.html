Operator

Usage & Getting Started

1What This Is

A local workbench running many coding-agent sessions in parallel.

Operator is a local instance at http://localhost:3000 running on your Mac. It is forked from operator-oss and integrated with your stack. The idea: every coding task gets its own dedicated agent session in its own isolated git worktree. This means parallel work never collides - you review a diff and merge when you're happy.

Operator runs as a launchd service on your Mac, so it's always on. Start a task, it streams progress live. Watch it work, answer questions if it asks, then review the diff and merge. Clean separation between sessions means you can safely run 10 tasks at once without tangled git states or conflicting edits.

2The Core Loop

How to work with Operator in 5 steps.

1
Create a Project

Point Operator at a git repo folder on your Mac. Click "New Project", paste the path, give it a name.

2
Add a Task

Give the task a title and description. That description becomes the agent's first prompt - be clear about what you want. Pick an agent (Claude Code or Codex) and any model/reasoning overrides you want.

3
Start Session & Watch

Click "Start". The agent streams work in real time. You see tool calls, code edits, test runs, everything. If it gets stuck or asks a question, the task shows "Needs your input" - answer inline.

4
Review the Diff

Click the DIFF tab in the task header. Review all changes at once. Does it look right? If not, edit it inline or ask the agent to adjust.

5
Merge & Done

Click Merge changes (one click into your main repo branch). Or generate a PR via gh pr create. Task is done. Use /clear to save a summary and start fresh on the same task with a clean context window.

3Agents

Two AI agents available, pick per task.

Claude Code: Your Max login (Claude 5, Sonnet, Haiku, Fable). Connected to Anthropic directly.

Codex: Your ChatGPT login, routed through the local opencodex proxy on port 10100. This is how GPT models (gpt-5.6-sol and others) appear in Operator.

Each task shows agent controls in the header. You pick Claude or Codex at creation, and can override the model, reasoning level, or permissions on the fly. Task-level picks override defaults.

4Quota Fuel Gauge

Live usage tracking in the top bar.

The tiny C/X strip in the topbar shows real-time quota. Green = under 50% used. Amber = 50-79% used. Red = 80% or more used.

Click the gauge or the gauge icon to open Provider Quotas view. You'll see:

  • Claude: 5-hour session window + weekly limits
  • Codex: weekly limits
  • Countdown to next reset
  • Recent per-model usage (Fable highlighted) from the local session index

All percentages shown are percent used of your quota, not remaining.

5The Handoff

The killer feature: seamless agent swap mid-task.

When Claude runs low on quota (amber banner appears at your threshold, default 80%, adjustable in Settings), open any running Claude task and look at the task header. You'll see "Continue with Codex". Click it twice - first click arms it, second click confirms.

Here's what happens: the session is summarized, the same task continues on Codex in the same worktree with that summary as context. No file state is lost. The button flips to "Continue with Claude Code" if you want to swap back.

This is how you run unlimited coding sessions without hitting quota walls. Handoff mid-task, pick up exactly where you left off.

6iPhone Access

Access Operator on your phone over Tailscale.

If you have Tailscale connected on your iPhone and your Mac, open Safari and navigate to:

iOShttp://geos-mbp:3000

Or use your Mac's Tailscale IP address. Then:

  1. Tap Share button at the bottom
  2. Scroll right and tap Add to Home Screen
  3. Tap Add in the top-right corner

It launches as a standalone app icon on your home screen. Perfect for checking on running tasks while away from your desk. Your Mac must be awake for phone access to work.

8Ops Cheatsheet

Copy-paste commands for ops work.

Restart Operator app
launchctl kickstart -k gui/$UID/com.geo.operator
Restart PTY sidecar (terminal panes)
launchctl kickstart -k gui/$UID/com.geo.operator-pty
Rebuild after code changes, then restart
cd "/Users/geo/Claude Projects/operator" && npm run build && launchctl kickstart -k gui/$UID/com.geo.operator
Manual run (dev mode)
npm run start:geo
Watch logs in real time
tail -f "/Users/geo/Claude Projects/.services/logs/operator.err"

9Troubleshooting

Quick fixes for common issues.

Page won't load or app feels slow

Check the Services Dashboard at http://localhost:8765. If Operator shows as down, click Restart. Otherwise, run: launchctl kickstart -k gui/$UID/com.geo.operator

Quota gauge empty (no numbers showing)

The opencodex proxy on port 10100 may be down. Run: launchctl kickstart -k gui/$UID/com.opencodex.proxy

Codex tasks show "no output" on verify

This is a known issue in the upstream but already patched in this fork. If it still happens, check the logs at /Users/geo/Claude Projects/.services/logs/operator.err

Terminal panes (PTY) are dead or unresponsive

The PTY sidecar runs on port 3101 and can get stuck. Restart it: launchctl kickstart -k gui/$UID/com.geo.operator-pty

Phone can't reach Mac after sleep

Your Mac must be awake for Tailscale to route traffic. Wake it up, make sure Tailscale is running on both devices, then try again.
