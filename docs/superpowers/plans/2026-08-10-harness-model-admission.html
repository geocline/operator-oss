Harness Model Admission Implementation Plan

For agentic workers: REQUIRED SUB-SKILL: use executing-plans and implement every task test-first.

Goal: Present only Harness → Model → Strength, offer every model proven compatible with that harness, and keep LiteLLM invisible as routing infrastructure.

Architecture: Preserve concrete route/harness drivers internally, but add a public harness catalog that merges their model options. Each model option carries its internal driver ID. Selection resolves the hidden driver automatically. LiteLLM admission metadata gates which pairs enter the public catalog.

Tech stack: Next.js/React/TypeScript, Claude Agent SDK, Codex SDK, Prime JSONL RPC, LiteLLM HTTP relay, Vitest.
