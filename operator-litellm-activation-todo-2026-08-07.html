What is still needed to activate paid Operator models

The code is installed and verified. These operational steps require Geo's provider credential/model choices and were intentionally not guessed or performed.

  1. Create a separate OpenRouter API key for company-billable Operator usage.
  2. Add it to ~/.litellm/.env as OPENROUTER_OPERATOR_API_KEY.
  3. Add one or more model_list deployments in LiteLLM with model_info.operator.enabled: true, kind: coding, and harnesses: ["codex"]. Point each deployment at the dedicated key.
  4. Run scripts/validate-config.sh and scripts/reload.sh in the LiteLLM server folder.
  5. Restart Operator if its currently running process predates the build, then open Settings → Agents → LiteLLM · Codex harness → Refresh models.
  6. Select a model on a low-risk test task. This is the first step that may incur provider charges.

Not part of this activation: native Claude Code and native Codex remain on their existing subscription routes.
