Model and accounting controls

Only Kimi was reachable

The isolated Prime configuration exposed one custom provider containing one model. OpenRouter resolved the requested alias to moonshotai/kimi-k3-20260715 on Fireworks. No OpenAI or Anthropic model was invoked.

Costs reconcile exactly

Prime’s $0.0337104 estimate equals the sum of all seven authoritative OpenRouter generation records and the final dedicated-key counter delta.

Token breakdown

3,771 uncached input, 16,808 cached input, and 1,157 completion tokens. OpenRouter identified 756 native reasoning tokens inside the completions.

Secrets and state were isolated

The API key stayed in macOS Keychain and process memory. Artifact scanning found no OpenRouter secret, telemetry was disabled, and auto-refinement was disabled.

What the first test revealed

Correct, but slightly tool-heavy

The tool gate took three IPython calls. The third read the README after the required facts and hash were already available. That is a small efficiency penalty to compare against the Claude Code and Codex harnesses.

Abort normalization needs care

Prime reported the interrupted assistant turn with stopReason=toolUse while the tool result carried the actual error/abort signal. An Operator driver must use both event layers when deciding whether a stop succeeded.

RPC startup is intentionally silent

The first instrumentation attempt waited for a startup session event that RPC mode does not emit. It stopped before inference, cost $0, and was preserved. The runner now uses get_state, matching Prime’s RPC implementation.

Key counters update asynchronously

The dedicated-key counter briefly showed $0.0201909 before converging to $0.0337104. The runner now verifies generation metadata first and polls the key counter before finalizing cost.
